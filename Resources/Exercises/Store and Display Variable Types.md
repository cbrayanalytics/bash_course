### Goal:
Create a script named `variables.sh` that declares and displays different types of variables (strings, numbers, mixed content).

### Requirements:
- [x] Declare at least 3 string variables
- [x] Declare at least 3 numeric variables
- [x] Display all variables with descriptive labels
- [x] Demonstrate variable concatenation
### Hints:
- Bash treats everything as strings by default, but you can still store numbers
- Use `echo` with clear labels to show each variable
- You can concatenate variables in echo statements
### Expected Output Example:
```
Name: John Doe
Age: 30
City: Denver
Score: 95
Year: 2025
Count: 42
Full Info: John Doe is 30 years old
```
