30-Day Bash Scripting Course
This repository contains an introductory to intermediate-level Bash course designed to be completed over 30 days. The daily layout serves as a suggested structure, but you are free to work through the material at your own pace.
The course is optimized for use within Obsidian, a powerful, markdown-based note-taking application. Obsidian allows for easy navigation of lessons, exercises, and projects through its “vault” system.
Getting Started with Obsidian
	1.	Visit https://obsidian.md.
	2.	Download and install Obsidian for your operating system.
	3.	Clone or download this repository and open the folder as a new vault in Obsidian.
